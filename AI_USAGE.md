# AI Usage Declaration

AI tools were used during the development of this project for guidance, debugging assistance, architecture planning, and code improvement.

The following AI-assisted support was used:

- Understanding RAG architecture
- FastAPI integration guidance
- Streamlit frontend guidance
- ChromaDB integration debugging
- Prompt engineering suggestions
- Retrieval pipeline improvements
- Multilingual support ideas
- Error debugging and dependency resolution

All code was manually reviewed, tested, modified, and integrated into the final project by the author.

The final implementation, debugging, testing, and project integration were completed manually.

AI assistance was used as a development support tool and not as a replacement for understanding or implementation.
